Integration (2026-10-14):
- M3 routing reads the latest valid M2 score of **every segment a candidate route follows**
  (`_segment_risk` in `backend/routing/router.py`), not only segments holding an M1 event.
  Route risk = max(point-hazard exposure, segment risk); a high M2 segment alone can trigger a reroute.
- M4 uses `risk_level` (4 levels), `maintenance_priority`, `predicted_condition` and top factors
  (Equipment → *Priorités d'entretien*; Transport → *Réseau à risque* + governorate forecasts).
