# M1 — Perception

## Goal
Transform a citizen road image or inspection-vehicle video into geolocated,
measured road-damage observations and deduplicated RoadEvents.

## Implemented v2 pipeline
1. Upload image/video to the persistent media volume.
2. Create a durable `perception_jobs` row.
3. M1 worker claims jobs with `FOR UPDATE SKIP LOCKED`.
4. OpenCV decodes media; video is sampled by time (default 5 FPS).
5. Frames are inferred in batches with a fine-tuned Ultralytics detector.
6. RDD2022 labels map to longitudinal crack, transverse crack, alligator crack and pothole.
7. Vehicle frame timestamps are aligned to `inspection_positions` by GPS interpolation.
8. Every prediction is stored as `road_observations`.
9. Nearby, recent observations of the same defect class merge into one `road_event`.
10. New events are published through the durable notification outbox.

## Model strategy
For a new 2026 project, compare **YOLO26n**, **YOLO26s** and **YOLO11n**. The
nano candidate is the deployment baseline; the small candidate tests whether the
accuracy gain justifies additional latency. Selection uses measured mAP50-95,
precision, recall, inference latency and model size, not a hard-coded winner.

## Dataset
Start with RDD2022 and its four standard damage classes D00, D10, D20 and D40.
Use `prepare_rdd2022.py` for deterministic train/validation/test conversion. For
real deployment, collect a Tunisia pilot set and report performance separately on
that local domain before claiming field accuracy.

## Validation evidence
- mAP@0.5 and mAP@0.5:0.95
- precision / recall, including per-class results
- latency and effective FPS on the target hardware
- checkpoint size
- false positives by class
- video-level duplicate reduction after spatial-temporal merging
- a local Tunisia pilot set, kept separate from training during final evaluation

The `severity_proxy` is only a visual prioritization signal. Engineering severity
must not be presented as measured depth/width unless the camera is calibrated or
additional depth sensing is available.
