# M4 — Platform: task brief
M5 supplies only a temporary status page; M4 replaces it with the product UI.
- Role-specific views: citizen, driver, Equipment employee, Transport supervisor.
- OSM map with road events, risk and routes.
- Citizen reporting workflow.
- Driver alert/reroute workflow.
- Transport supervisor can add/manage official routes and observe reroutes.
- Finalize authentication/authorization needs with M5; prototype identity is intentionally flexible.
**Evidence:** navigable end-to-end smartphone + transport rerouting demo.
