# M5 — Foundation and integration

M5 owns the stable cross-module contracts: Docker Compose, FastAPI, PostGIS,
Alembic, local persistent media, JWT roles, the notification outbox, optional
MLflow, CI and integration tests.

The normal start path is `docker compose up -d --build`. Schema changes are made
with Alembic revisions, not numbered SQL files. Large media files are stored on a
persistent Docker volume and referenced by key/URL from the database.
